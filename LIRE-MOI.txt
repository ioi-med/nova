Recompiler :

    cargo test                                   # 29 tests unitaires
    cargo build --release                        # Windows (chaîne MSVC)
    # ou, depuis Linux :
    bash tools/install_chain.sh
    cargo xwin build --release --target x86_64-pc-windows-msvc
    bash tools/package.sh
